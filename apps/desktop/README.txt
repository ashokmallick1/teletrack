========================================
TeleTrack Windows Desktop Agent
========================================

How to Run on Windows:
1. Ensure Node.js is installed (https://nodejs.org).
2. Double-click "run-teletrack.bat" to start the Desktop Agent.
3. Sign in with your TeleTrack employee credentials and Organization Join Code (e.g. acme-teleservices).
4. The agent will dock into your Windows System Tray and track foreground applications, window titles, active vs idle time, and productivity metrics in sync with your mobile SIM calls!
